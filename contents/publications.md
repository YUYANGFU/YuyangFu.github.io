#### Projects & Preprints

- **AgentCPM-Explore: An End-to-End Infrastructure for LLM Agents** [[GitHub](https://github.com/OpenBMB/AgentCPM)]
    - **Role:** Core Contributor. Responsible for the **inference part** of the agent framework and the **evaluation (AgentToLeaP)** platform.
    - AgentCPM-Explore is the first open-source 4B-parameter agent model to appear on 8 widely used long-horizon agent benchmarks (e.g., GAIA, xBench-DeepSearch). It achieves state-of-the-art performance at the 4B scale, rivaling much larger closed-source models. (Work at THUNLP Lab)

- **Adversarial Evaluation & Optimization of Machine Unlearning in LLMs**
    - **Role:** Undergraduate Researcher
    - Reproduced and evaluated the SimNPO framework, identifying catastrophic forgetting modes undetected by standard benchmarks. Engineered a 1,000+ sample adversarial dataset and developed metrics to establish the trade-off curve between unlearning efficacy and model utility. (Work at Cybersecurity Policy & Research Institute, UCI)

- **RAG-Enhanced LLM Agent with MCP-based Tool Integration**
    - Developed an LLM agent client using the Model Context Protocol (MCP) to integrate Playwright-based browser tools. Enabled the agent to autonomously complete long-horizon, complex web-browsing tasks with RAG-enhanced context retrieval. (Personal Project)
